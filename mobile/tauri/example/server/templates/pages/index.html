How it works

Phones sleep. Servers don't. Split the job accordingly.

Server

Runs a job on a schedule

An Apalis background job fires every {{ poll_interval_mins }} minutes and appends a row to SQLite with a monotonic sequence number. Swap the job body for whatever your server actually does.

Device

Mirrors from a cursor

The app keeps its own SQLite copy and asks "anything past sequence N?" while it's open. Reads work offline; the first sync is a quiet backfill.

Shared

One contract, compiled twice

The request and wire types live in one crate that both the server and the app compile, so the two sides cannot drift. The server's plumbing comes from the same core library as the web services.
