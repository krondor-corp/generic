How it works

Phones sleep. Servers don't. Split the job accordingly.

Server

Scrapes on a schedule

An Apalis background job pulls the top-story ids every {{ poll_interval_mins }} minutes, fetches only the ones it hasn't seen, and appends them to SQLite with a monotonic sequence number.

Device

Mirrors from a cursor

The app keeps its own SQLite copy and asks "anything past sequence N?" while it's open. Reads work offline; the first sync is a quiet backfill.

Notify

Tells you locally

New rows become a local notification on the device. No APNs, no Firebase, no account: the server never knows who you are beyond an anonymous install id.
